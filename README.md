# スカイライン・テクノロジーズ 企業サイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ株式会社」のデモ用企業サイトです。
`index.html` 1ファイルで構成された静的サイトで、ビルドやサーバーは不要です。

## サイトの概要

建築図面をモチーフにしたデザインで、各セクションをビルの「階」に見立てています。
ヒーロー部分では、屋上の航空障害灯が点滅するスカイラインを Canvas で描画しています。

| セクション | 内容 |
| --- | --- |
| お知らせ | プレスリリース・採用・イベントの最新情報 |
| ヒーロー | キャッチコピーと会社紹介、スカイラインのアニメーション |
| 事業内容（4F） | 受託システム開発／クラウド基盤構築／モバイルアプリ開発／DX・技術コンサルティング |
| 実績（3F） | 物流・医療・小売分野の導入事例と成果指標 |
| 開発の進め方（2F） | 要件定義から運用・改善までの工程 |
| 会社概要（1F） | 会社情報と主要な数値 |
| 採用（GL） | 募集中の職種 |
| お問い合わせ（B1） | 連絡先と問い合わせフォーム |

### 主な特徴

- スマートフォンからPCまで対応するレスポンシブレイアウト
- OSの設定に合わせたライトモード／ダークモードの自動切り替え
- OSでアニメーションを減らす設定が有効な場合は、スクロールと点滅アニメーションを抑制
- お問い合わせフォームは入力チェックのみ行い、実際には送信しません（デモのため）

## ブラウザで index.html を開く手順

### 方法1: ファイルを直接開く

1. エクスプローラーでこのフォルダ（`company-site`）を開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザでサイトが表示されます。

別のブラウザで開きたい場合は、`index.html` を右クリックし、「プログラムから開く」でブラウザを選択してください。
`index.html` をブラウザのウィンドウにドラッグ＆ドロップしても開けます。

### 方法2: コマンドラインから開く

PowerShell でこのフォルダに移動し、次のコマンドを実行します。

```powershell
start index.html
```

### 方法3: ローカルサーバーで開く（任意）

`http://localhost` のURLで確認したい場合は、簡易サーバーを起動します。Python がインストールされている場合は次のとおりです。

```powershell
python -m http.server 8000
```

起動後、ブラウザで <http://localhost:8000/> を開いてください。停止するときは `Ctrl + C` を押します。

## 補足

- フォント（Archivo、IBM Plex Mono、Zen Kaku Gothic New）は Google Fonts から読み込んでいます。オフライン環境ではシステムフォントで表示されます。
- 掲載している社名・住所・電話番号・実績などはすべて架空のものです。
